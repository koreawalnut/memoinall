# 📘 `memoinall` 소개 및 실무 활용 가이드

이 문서는 **`memoinall(메모인올)`**의 기획 배경, 핵심 기능, 도입 효과(창의성·실무 활용성·공유 가능성) 및 설치·세팅 방법을 정리한 설명 가이드입니다.
함께 제공되는 **[인터랙티브 HTML 슬라이드(`docs/contest-presentation.html`)](contest-presentation.html)**를 브라우저(Edge/Chrome)로 열면 실제 캡처 화면을 마우스로 드래그 앤 드롭하여 발표 자료나 PDF 안내서로 바로 활용하실 수 있습니다.

---

## 1. 핵심 주안점 (5대 업무 흐름)

`memoinall`은 일상 업무에서 기록하고 자료를 찾아 문서를 만들고 공유하는 **5가지 핵심 과정**을 가장 쉽고 빠르게 연결하는 데 집중했습니다.

1. **쉽게 메모 (Easy Memo):** 폴더나 양식 고민 없이 입력창 하나에 바로 적고(`Ctrl+Enter`), 작성 중 초안이 자동 보관·복원되며 본문이나 상세 화면에서 **`#태그`를 손쉽게 추가·편집**할 수 있습니다.
2. **빠르게 검색 (Fast Search):** **`#태그` 필터로 주제·업무별 메모를 한 번에 모아 볼 수 있고**, 정확한 단어가 기억나지 않아도 찾아주는 **의미 기반 벡터 검색 + 한글 2-gram 키워드 검색(하이브리드 검색)**과 작성일·사람 조건을 조합해 필요한 기록을 바로 찾습니다.
3. **AI 활용 (AI Utilization):** 설정에서 **사용할 AI(Claude, ChatGPT, Gemini 등)를 세팅**해 두면, 지시사항에 따른 다각도 검색, **현재 `#태그` 검색 범위, 또는 체크박스로 직접 고른 메모**를 근거로 **원문 출처(`[M번호]`)가 표시된 정리 결과물**을 생성합니다.
4. **다른 메모·문서 쉽게 가져오기 (Easy Import):** 기존에 쓰던 **Windows 스티커 메모, 삼성 노트, 에버노트(`.enex`), Redmine**은 물론 **엑셀(`.xlsx`/`.xls`), 한글(`.hwp`/`.hwpx`), PDF, 텍스트 파일**까지 미리보기로 원하는 시트·페이지·노트만 골라 분류용 `#태그`와 함께 손쉽게 가져옵니다.
5. **쉽게 공유 (Easy Share):** 동료에게 업무 자료를 전달하거나 인수인계할 때 **특정 `#태그`(예: `#인수인계`, `#프로젝트A`)와 기간 조건으로 보낼 메모를 한 번에 추리거나** 체크박스로 골라 나갈 목록을 미리 확인하고, **비밀번호 암호화(AES-256-GCM) 파일(`.json`)**로 안전하고 간편하게 주고받습니다.

## 2. 프로젝트 소개 및 주요 강점

### 📌 제목 예시 (택 1)
1. **쉽게 적고, 빠르게 찾아, AI로 문서화·공유하는 올인원 업무 보조 도구 `memoinall`**
2. **흩어진 메모와 엑셀·한글(HWP)·PDF를 한곳에 모아 AI 보고서·인수인계서로 바꾸는 `memoinall`**
3. **적을 땐 무형식, 꺼낼 땐 AI 구조화 문서로! — 스마트 업무 기록·공유 도구 `memoinall`**

### 📌 한 줄 요약
> 복잡한 양식 없이 **쉽게 메모**하고, 단어가 가물가물해도 **빠르게 검색**하며, 내가 세팅한 **AI를 활용해 원문 출처(`[M번호]`)가 붙은 보고서·인수인계서**를 만들고, **외부 메모·문서(엑셀·한글·PDF) 가져오기**부터 **동료 공유**까지 하나로 해결하는 설치형 업무 보조 도구입니다.

---

### 📌 세 가지 측면에서 본 `memoinall`의 강점

#### ① 창의성 — 기존 업무 방식을 어떻게 새롭게 정의했는가?
- **기존의 불편함 ("적는 순간 분류를 강요하는 부담과 파편화된 기록"):**
  - 회의나 통화 중 폴더, 제목, 양식을 먼저 맞추려다 보니 기록을 미루거나 스티커 메모·메모장·엑셀·한글 파일 등 여러 곳에 흩어져 정작 필요할 때 찾지 못합니다.
  - 또한 AI로 보고서나 인수인계서를 쓰려면 흩어진 자료를 일일이 찾아 복사·붙여넣어야 하고, AI가 어떤 근거로 문장을 썼는지 원문을 대조하기 어려웠습니다.
- **새로운 접근 ("적을 땐 무형식, 꺼낼 땐 구조화"):**
  1. **무형식 즉시 기록 & 초안 보호:** 사용자는 단일 입력창에 양식 없이 적고 `Ctrl+Enter`만 누릅니다. 작성 중인 내용은 자동으로 초안 보관되어 창이 닫혀도 복원되며, 백그라운드에서 검색 색인과 `#태그`, `@사람` 정보를 자동 정리합니다.
  2. **의미 + 한글 2-gram 하이브리드 검색(RRF):** 조사가 붙어 다니는 한국어 특성(*'회의록을'*)을 해결하는 **한글 2-gram 검색**과 문맥·유사 개념을 찾는 **의미 기반 벡터 검색**을 결합해, 단어가 정확히 기억나지 않아도 원하는 메모를 즉시 찾아냅니다.
  3. **다각도 검색 & 원문 출처(`[M번호]`) 연결 AI 생성:** 사용할 AI를 세팅한 뒤 지시사항(*"연수원 세미나 기획안 초안 써줘"*)을 입력하면 다각도의 검색 질의를 도출해 관련 메모를 모으거나, **사용자가 체크박스로 직접 고른 메모만** 근거로 삼아 문서를 작성합니다. 결과물의 `[M12]` 링크를 클릭하면 즉시 원본 메모가 열려 사실 여부를 바로 확인할 수 있습니다.

#### ② 실무 활용성 — 5대 핵심 기능이 기존 업무를 어떻게 바꾸는가?

5대 핵심 기능별로 기존 방식의 번거로운 단계가 어떻게 줄어드는지(Before & After)와 실측된 기술 지표를 제시합니다.

| 5대 핵심 기능 | 기존 방식 (Before) | `memoinall` 활용 (After) | 핵심 개선점 |
| :--- | :--- | :--- | :--- |
| **① 쉽게 메모** | 메모할 때마다 폴더·제목·양식을 먼저 고민해야 하고, 작성 중 창을 닫으면 적던 내용이 사라짐 | 분류 강요 없이 단일 입력창에 바로 적고(`Ctrl+Enter`), **초안 자동 보관·복원 및 간편한 `#태그` 추가·편집** 지원 | **기록 장벽 해소 & 작성 내용 유실 방지** |
| **② 빠르게 검색** | 정확한 단어가 기억나지 않거나 한글 조사가 다르게 붙으면 검색되지 않아 목록을 일일이 찾아야 함 | **의미 벡터 + 한글 2-gram 하이브리드 검색**에 **`#태그`·작성일·`@사람` 필터**를 조합해 주제별 메모를 즉시 탐색 | **`#태그` & 문맥 검색으로 원하는 메모 즉시 탐색** |
| **③ AI 활용** | AI에게 정리를 맡기려면 관련 메모를 일일이 찾아 복사·붙여넣어야 하고, 결과물의 원문 근거 확인이 어려움 | 세팅한 AI로 다각도 검색·**현재 `#태그` 필터 범위·직접 고른 메모**를 근거로 정리하고, **`[M번호]`로 원문 즉시 열람** | **수작업 복붙 제거 & 원문 출처 즉시 확인** |
| **④ 쉽게 가져오기** | 스티커 메모, 삼성 노트, 에버노트, Redmine이나 엑셀·한글(HWP)·PDF에 내용이 흩어져 통합 활용 불가 | 외부 앱 메모와 문서(시트·페이지·구역 선택)를 가져오며 **출처·분류용 `#태그`를 자동 부여**해 검색·공유에 연결 | **흩어진 외부 메모와 문서의 손쉬운 통합** |
| **⑤ 쉽게 공유** | 전체 메모 중 동료에게 필요한 기록만 골라내기 번거롭고, 전달 전 내용 확인이나 파일 암호화가 어려움 | **특정 `#태그`·기간 조건**으로 보낼 메모를 한 번에 추린 뒤, **본문 확인·체크박스 선택** 후 **AES-256 암호화 파일(`.json`)**로 교환 | **`#태그` 범위 지정 & 확인 후 안전 핀셋 공유** |

- **프로젝트 실측 수치 (`README.md` 및 검증 문서 근거):**
  - **실행 파일 경량화 및 모델 로딩 속도 실측:** 무거운 PyTorch+Transformers(590MB, 전체 묶음 시 1GB 이상) 대신 **ONNX Runtime(49MB)**을 적용해 단일 실행 파일 **54MB**(설치 파일 `Setup.exe` **46.2MB**)로 경량화하고, 임베딩 모델 로드 시간을 **17.8초 → 1.5초**로 단축했습니다(가중치 동일, 코사인 유사도 1.0).
  - **토큰 예산 맞춤 실측:** 19,000자짜리 긴 메모가 섞인 실제 데이터에서 예산 **3,000토큰** 지정 시 **2,999토큰을 사용해 근거 12건**을 빠짐없이 수록합니다(예산 맞춤이 없으면 긴 메모 1건에 10,954토큰이 소모되어 다른 근거가 누락되는 문제 해결).
  - **하이브리드 검색 및 품질 검증 실측:** 어휘가 겹치는 현실적 질의 **Top-1(9/9)**, 어휘가 전혀 안 겹치는 은유적 질의(*"돈이 많이 새고 있는 곳"* → 서버 비용 메모) **Top-3(5/6)** 적중을 확인했으며, Python 자동화 테스트 **658건 통과** 및 Playwright 브라우저 주요 흐름 **16종 시나리오 검증**을 완료했습니다.

#### ③ 공유 가능성 — 다른 부서나 팀원들도 얼마나 쉽게 따라 쓸 수 있는가?
1. **개발 환경이 전혀 필요 없는 원클릭 설치 파일 (`memoinall-Setup-0.1.0.exe`):**
   - Python 설치나 복잡한 명령어 없이, **설치 파일 하나(약 46MB)**만 전달하면 관리자 권한 없이도 PC에 즉시 설치되고 시작 메뉴에서 바로 실행됩니다.
2. **유연한 AI 세팅 (Claude · ChatGPT · Gemini 등) 및 프롬프트 복사 지원:**
   - **[더 보기 → 설정]** 화면에서 본인이 사용하는 AI 프로바이더와 모델, API 키를 입력하고 **저장 전 `연결 테스트`**로 손쉽게 세팅할 수 있습니다.
   - 별도의 API 키를 세팅하지 않은 경우에도, 검색된 근거 메모가 깔끔하게 정리된 **‘완성형 프롬프트’**를 원클릭 복사하여 사내 웹 AI나 무료 챗봇에 붙여넣어 똑같이 활용할 수 있습니다.
3. **배우기 쉬운 3대 메뉴 UI와 안전한 동료 공유:**
   - 복잡한 메뉴를 숨기고 **[내 메모] · [AI로 정리] · [가져오기·공유]** 3개 주메뉴로 단순화하여 별도 교육 없이 바로 적응할 수 있습니다.
   - 동료와 메모를 주고받을 때도 보낼 목록과 받을 목록의 본문을 미리 확인하고 체크박스로 골라 **AES-256-GCM 비밀번호 암호화 파일(`.json`)**로 안전하게 교환할 수 있습니다.

## 3. 📸 화면 캡처 가이드 (본편 5장 + 부록 3장)

실제 사용 화면을 캡처하실 때 아래 장면을 준비해 `docs/contest-presentation.html`의 각 슬롯에 마우스로 끌어다 놓으시면 슬라이드가 바로 완성됩니다.

### [캡처 1] 전체 메인 화면 (`내 메모` 탭) — *표지(슬라이드 1)용*
- **촬영 포인트:** 앱 창 전체가 보이도록 캡처합니다. 상단/좌측의 **내 메모 · AI로 정리 · 가져오기·공유** 3대 주메뉴와 메모 입력창·검색창·메모 목록이 한눈에 들어오면 좋습니다.

### [캡처 2] 쉽게 메모 & 빠르게 검색 (`내 메모` 검색·필터) — *슬라이드 3용*
- **촬영 포인트:**
  - 메모 입력창(`초안 보관됨` 표시 등)과 함께, 검색어 입력 또는 **`상세 검색`을 펼쳐 `작성일`, `#태그`, `@사람` 조건으로 원하는 메모를 빠르게 걸러낸 화면**을 캡처합니다.

### [캡처 3] AI 활용 (`AI로 정리` 결과 및 `[M번호]` 출처 링크) — *슬라이드 4용*
- **촬영 포인트:**
  - **AI로 정리** 탭에서 지시사항을 입력하고 출력 형식(**`인수인계서`** 또는 **`보고서`**)을 선택해 생성된 결과 화면을 캡처합니다.
  - 화면에 **도출된 검색 질의/근거 메모 목록(또는 직접 선택한 메모 범위)**과 함께 결과 본문에 **`[M1]`, `[M2]` 원문 열기 링크**가 선명하게 보이도록 캡처하세요.

### [캡처 4] 다른 메모·문서 쉽게 가져오기 (`가져오기·공유 → 다른 앱에서 가져오기`) — *슬라이드 5용*
- **촬영 포인트:**
  - 스티커 메모 / 삼성 노트 / 에버노트(`.enex`) / Redmine 가져오기 화면이나,
  - **`파일을 메모로 가져오기`**에서 실제 엑셀(`.xlsx`), 한글(`.hwp`/`.hwpx`), PDF 파일을 올려 **시트·페이지·구역별 텍스트 미리보기와 체크박스 선택**이 뜬 화면을 캡처합니다.

### [캡처 5] 쉽게 공유 (`가져오기·공유 → 동료와 주고받기`) — *슬라이드 6용*
- **촬영 포인트:**
  - **동료와 주고받기**에서 보낼 메모(또는 받은 `.json` 파일)의 목록·본문을 미리 보고 체크박스로 선택해 비밀번호 암호화로 내보내거나 가져오는 화면을 캡처합니다.

### [캡처 6 & 7] 프로그램 설치 및 첫 실행 화면 — *부록 A(슬라이드 9)용*
- **[캡처 6] 촬영 포인트:** `memoinall-Setup-0.1.0.exe`를 실행했을 때 뜨는 Windows 설치 마법사 화면(설치 위치 확인 또는 바탕화면 바로가기 선택 화면)을 캡처합니다.
- **[캡처 7] 촬영 포인트:** 설치 완료 화면이나 시작 메뉴에서 처음 실행된 화면(사이드바에 검색 모델 준비/완료 상태가 표시된 화면 등)을 캡처합니다.

### [캡처 8] 사용할 AI 초기 세팅 화면 (`더 보기 → 설정`) — *부록 B(슬라이드 10)용*
- **촬영 포인트:** **더 보기 → 설정**에서 사용할 AI(Claude · ChatGPT · Gemini · Ollama 등)를 고르고, API 키(마스킹 표시)·모델 선택 및 **`연결 테스트` 성공 메시지**가 표시된 화면을 캡처합니다.

## 4. 💿 부록: 동료 배포용 설치 및 초기 세팅 안내문

동료들에게 설치 파일을 공유하거나 게시판에 함께 안내할 때 그대로 복사해 사용할 수 있는 가이드입니다.

> ### 🛠️ `memoinall` 1분 설치 및 AI 세팅 방법
> 
> **1단계: 프로그램 설치 (`memoinall-Setup-0.1.0.exe`)**
> 1. 첨부된 `memoinall-Setup-0.1.0.exe` 파일(약 46MB, Windows 10/11 64비트용)을 내려받아 실행합니다.
> 2. Python 설치나 관리자 권한이 필요하지 않으며, 기본 경로(`%LOCALAPPDATA%\Programs\memoinall`)에 바로 설치됩니다.
> 3. 바탕화면 바로가기 만들기를 체크하고 설치를 완료한 뒤, 시작 메뉴 또는 바탕화면에서 **`memoinall`**을 실행합니다.
>    - *참고:* 첫 실행 시 의미 검색에 필요한 모델을 백그라운드로 자동 준비하며, 준비 중에도 기다리지 않고 바로 메모 작성·저장·키워드 검색을 사용하실 수 있습니다.
>    - *데이터 보존:* 작성한 메모와 설정은 `%USERPROFILE%\.memoinall`에 별도 저장되므로 추후 새 버전을 덮어써 업데이트하거나 프로그램을 삭제해도 메모는 안전하게 유지됩니다.
> 
> **2단계: 사용할 AI 세팅 (`더 보기 → 설정`)**
> 1. 앱 상단 메뉴에서 **[더 보기 → 설정]**을 클릭합니다.
> 2. **Claude · ChatGPT · Gemini · Ollama** 중 본인이 사용할 AI 프로바이더를 선택합니다.
> 3. API 키를 입력하고 모델을 선택한 뒤(`서버에서 모델 목록 불러오기` 지원), 저장하기 전에 **`[연결 테스트]`** 버튼을 눌러 정상 연결을 확인하고 **`[저장]`**을 누릅니다.
>    - *Tip:* 별도의 API 키가 없더라도 설정 없이 **[AI로 정리]**를 실행하면 관련 메모 근거가 정리된 **완성형 프롬프트**를 만들어주므로, 사내 AI나 무료 웹 챗봇에 그대로 복사·붙여넣어 활용하실 수 있습니다!
