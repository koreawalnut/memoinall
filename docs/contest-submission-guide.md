# 📘 `memoinall` 소개 및 실무 활용 가이드

이 문서는 **`memoinall(메모인올)`**의 기획 배경, 핵심 기능, 도입 효과(창의성·실무 활용성·공유 가능성) 및 설치·세팅 방법을 정리한 설명 가이드입니다.
함께 제공되는 **[인터랙티브 HTML 슬라이드(`docs/contest-presentation.html`)](contest-presentation.html)**를 브라우저(Edge/Chrome)로 열면 실제 캡처 화면을 마우스로 드래그 앤 드롭하여 발표 자료나 PDF 안내서로 바로 활용하실 수 있습니다.

---

## 1. 핵심 주안점 (5대 업무 흐름)

`memoinall`은 일상 업무에서 기록하고 자료를 찾아 문서를 만들고 공유하는 **5가지 핵심 과정**을 가장 쉽고 빠르게 연결하는 데 집중했습니다.

1. **쉽게 메모 (Easy Memo):** 폴더나 양식 고민 없이 입력창 하나에 바로 적고(`Ctrl+Enter`), 작성 중 초안이 자동 보관·복원되며 본문이나 상세 화면에서 **`#태그`를 손쉽게 추가·편집**할 수 있습니다.
2. **빠르게 검색 (Fast Search):** **`#태그` 필터로 주제·업무별 메모를 한 번에 모아 볼 수 있고**, 정확한 단어가 기억나지 않아도 찾아주는 **의미 기반 벡터 검색 + 한글 2-gram 키워드 검색(하이브리드 검색)**과 작성일·사람 조건을 조합해 필요한 기록을 바로 찾습니다.
3. **AI 활용 (AI Utilization):**
   - 설정에서 **사용할 AI(Claude, ChatGPT, Gemini 등)를 세팅**해 두면, 지시사항에 따른 다각도 검색, **현재 `#태그` 검색 범위, 또는 체크박스로 직접 고른 메모**를 근거로 **원문 출처(`[M번호]`)가 표시된 정리 결과물**을 생성하고, 화면에서 **직접 수정**하거나 **AI 다듬기**로 이어서 완성할 수 있습니다.
   - 매주·매월 반복하는 요청은 **‘자주 하는 업무’**에 **요청문(프롬프트)·태그·기간(`이번 주`, `이번 달` 등 실행일 기준 자동 계산)·출력 형식**과 함께 저장해 두고 원클릭으로 다시 불러와 실행할 수 있습니다.
4. **다른 메모·문서 쉽게 가져오기 & 엑셀 폴더 일괄 취합 (Easy Import & Excel Collection):**
   - 기존에 쓰던 **Windows 스티커 메모, 삼성 노트, 에버노트(`.enex`), Redmine**과 개별 **엑셀(`.xlsx`/`.xls`), 한글(`.hwp`/`.hwpx`), PDF, 텍스트 파일**을 미리보기로 원하는 시트·페이지·노트만 골라 분류용 `#태그`와 함께 손쉽게 가져옵니다.
   - 특히 부서별·담당자별로 받은 같은/비슷한 양식의 엑셀 파일들은 **[엑셀 폴더 취합]**에서 폴더만 고르면 **열 순서 차이·비슷한 열 이름·제목 줄·합계 행을 자동으로 맞춰 한 표로 모으고**, 앱이 전체 행을 정밀 계산한 뒤 **`엑셀로 저장`**하거나 **`이 자료를 AI로 정리`(`[C번호]` 행 출처 연결)**로 즉시 분석할 수 있습니다.
5. **쉽게 공유 (Easy Share):**
   - 동료에게 업무 자료를 전달하거나 인수인계할 때 **특정 `#태그`(예: `#인수인계`, `#프로젝트A`)와 기간 조건으로 보낼 메모를 한 번에 추리거나** 체크박스로 골라 나갈 목록을 미리 확인하고, **비밀번호 암호화(AES-256-GCM) 파일(`.json`)**로 안전하게 주고받습니다.
   - AI로 정리의 **‘자주 하는 업무’ 설정(프롬프트·태그·기간·형식)**도 개인 메모 없이 파일(`.json`)로 내보내 팀원들과 공유할 수 있습니다.

## 2. 프로젝트 소개 및 주요 강점

### 📌 제목 예시 (택 1)
1. **쉽게 적고, 빠르게 찾아, 엑셀 취합·AI 정리·공유까지 하나로 끝내는 업무 보조 도구 `memoinall`**
2. **흩어진 메모와 부서별 엑셀·한글(HWP)·PDF를 한곳에 모아 AI로 정리·공유하는 `memoinall`**
3. **적을 땐 무형식, 꺼낼 땐 AI 구조화 문서로! — 스마트 업무 기록·엑셀 취합·공유 도구 `memoinall`**

### 📌 한 줄 요약
> 복잡한 양식 없이 **쉽게 메모**하고, `#태그`와 하이브리드 검색으로 **빠르게 검색**하며, **자주 쓰는 프롬프트 저장(`자주 하는 업무`)과 세팅한 AI**로 **출처(`[M번호]`/`[C번호]`)가 붙은 결과물**을 만들고, **외부 메모·문서 가져오기 및 부서별 엑셀 폴더 일괄 취합·분석**부터 **동료 공유**까지 하나로 해결하는 설치형 업무 보조 도구입니다.

### 📌 세 가지 측면에서 본 `memoinall`의 강점

#### ① 창의성 — 기존 업무 방식을 어떻게 새롭게 정의했는가?
- **기존의 불편함 ("분류 부담, 파편화된 기록, 반복되는 엑셀 복붙과 프롬프트 재입력"):**
  - 회의나 통화 중 폴더, 제목, 양식을 먼저 맞추려다 보니 기록을 미루거나 여러 메모 앱·문서 파일에 흩어져 정작 필요할 때 찾지 못합니다.
  - 부서별로 제출받은 여러 개의 엑셀 파일을 합칠 때마다 파일을 하나씩 열어 열 순서를 맞추고 합계 행을 빼며 복사·붙여넣기를 반복해야 했습니다.
  - 또한 AI로 주간 정리나 보고서를 쓸 때마다 매번 관련 메모를 찾아 복붙하고 같은 프롬프트를 다시 입력해야 했으며, AI가 계산하거나 인용한 숫자의 원문 근거를 대조하기 어려웠습니다.
- **새로운 접근 ("적을 땐 무형식, 꺼낼 땐 구조화 + 앱이 정밀 계산하고 AI는 출처 기반으로 설명"):**
  1. **무형식 즉시 기록 & `#태그`·하이브리드 검색(RRF):** 단일 입력창에 양식 없이 적고 `Ctrl+Enter`만 누르면 초안 보호와 함께 색인·`#태그`가 정리되며, 한글 조사까지 처리하는 **한글 2-gram 검색**과 **의미 기반 벡터 검색**에 `#태그` 필터를 결합해 원하는 메모를 즉시 찾습니다.
  2. **부서별 엑셀 폴더 자동 취합 & 전체 행 정밀 계산:** **[엑셀 폴더 취합]**은 열 순서가 다르거나 비슷한 열 이름(공백·괄호·동의어 차이), 표 위 제목 줄, 2줄 머리글, 합계·반복 머리글 행을 자동으로 정리해 한 표로 합칩니다. 검색된 일부만 보고 AI가 합계를 추측하지 않도록 **앱이 전체 대상 행을 Decimal 정밀 연산으로 직접 집계(합계·평균·최소·최대·건수·빈칸/오류 구분)**하고, AI는 그 확정된 집계표와 행 출처(`[C번호]`)를 근거로 요약·보고서 초안을 작성합니다.
  3. **‘자주 하는 업무’ 저장 & 원문 출처(`[M번호]`) 연결·다듬기:** 반복하는 요청문(프롬프트)·태그·기간·형식을 **‘자주 하는 업무’**로 저장해 언제든 불러와 실행할 수 있습니다. 생성된 결과는 `[M번호]`/`[C번호]` 클릭으로 즉시 원문 메모나 취합표 행을 열어 대조할 수 있으며, **직접 수정**하거나 **AI 다듬기**로 이어서 완성할 수 있습니다.

#### ② 실무 활용성 — 5대 핵심 기능이 기존 업무를 어떻게 바꾸는가?

5대 핵심 기능별로 기존 방식의 번거로운 단계가 어떻게 줄어드는지(Before & After)와 실측된 기술 지표를 제시합니다.

- **프로젝트 실측 수치 (`README.md` 및 검증 문서 근거):**
  - **실행 파일 경량화 및 모델 로딩 속도 실측:** 무거운 PyTorch+Transformers(590MB, 전체 묶음 시 1GB 이상) 대신 **ONNX Runtime(49MB)**을 적용해 단일 실행 파일 **54MB**(설치 파일 `Setup.exe` **46.2MB**)로 경량화하고, 임베딩 모델 로드 시간을 **17.8초 → 1.5초**로 단축했습니다(가중치 동일, 코사인 유사도 1.0).
  - **토큰 예산 맞춤 실측:** 19,000자짜리 긴 메모가 섞인 실제 데이터에서 예산 **3,000토큰** 지정 시 **2,999토큰을 사용해 근거 12건**을 빠짐없이 수록합니다(예산 맞춤이 없으면 긴 메모 1건에 10,954토큰이 소모되어 다른 근거가 누락되는 문제 해결).
  - **전체 행 정밀 집계 및 자동화 검증:** 엑셀 폴더 취합 시 샘플 추정이 아닌 전체 대상 행 Decimal 집계(빈칸·열 없음·셀 오류·수식 미계산 분리, 앞자리 `0` 보존)를 수행하며, 하이브리드 검색(어휘 일치 **Top-1 9/9**, 은유 질의 **Top-3 5/6**) 및 Python·브라우저 UI 자동화 테스트를 통과했습니다.

#### ③ 공유 가능성 — 다른 부서나 팀원들도 얼마나 쉽게 따라 쓸 수 있는가?
1. **개발 환경이 전혀 필요 없는 원클릭 설치 파일 (`memoinall-Setup-0.1.0.exe`):**
   - Python 설치나 복잡한 명령어 없이, **설치 파일 하나(약 46MB)**만 전달하면 관리자 권한 없이도 PC에 즉시 설치되고 시작 메뉴에서 바로 실행됩니다.
2. **유연한 AI 세팅 (Claude · ChatGPT · Gemini 등) 및 프롬프트 복사 지원:**
   - **[더 보기 → 설정]** 화면에서 본인이 사용하는 AI 프로바이더와 모델, API 키를 입력하고 **저장 전 `연결 테스트`**로 손쉽게 세팅할 수 있습니다.
   - 별도의 API 키를 세팅하지 않은 경우에도, 검색된 근거 메모가 깔끔하게 정리된 **‘완성형 프롬프트’**를 원클릭 복사하여 사내 웹 AI나 무료 챗봇에 붙여넣어 똑같이 활용할 수 있습니다.
3. **안전한 메모 공유 & ‘자주 하는 업무’ 프롬프트 파일 공유:**
   - 동료와 메모를 주고받을 때 `#태그`·기간으로 추린 목록과 본문을 미리 확인하고 **AES-256-GCM 비밀번호 암호화 파일(`.json`)**로 안전하게 교환할 수 있습니다.
   - 또한 **[AI로 정리 → 자주 하는 업무 → 관리·공유]**에서 내가 만든 유용한 프롬프트·태그·기간·형식 설정만 `.json` 파일로 내보내 동료에게 전달하면, 받은 동료는 자기 팀 태그에 맞춰 저장해 즉시 똑같은 AI 자동화 업무를 실행할 수 있습니다.

## 3. 📸 화면 캡처 가이드 (본편 6장 + 부록 3장 = 총 9장)

실제 사용 화면을 캡처하실 때 아래 장면을 준비해 `docs/contest-presentation.html`의 각 슬롯에 마우스로 끌어다 놓으시면 슬라이드가 바로 완성됩니다.

### [캡처 1] 전체 메인 화면 (`내 메모` 탭) — *표지(슬라이드 1)용*
- **촬영 포인트:** 앱 창 전체가 보이도록 캡처합니다. 상단/좌측의 **내 메모 · AI로 정리 · 가져오기·공유** 3대 주메뉴와 메모 입력창·검색창·메모 목록이 한눈에 들어오면 좋습니다.

### [캡처 2] 쉽게 메모 & 빠르게 검색 (`내 메모` 검색·`#태그` 필터) — *슬라이드 3용*
- **촬영 포인트:** 메모 입력창(`초안 보관됨` 표시 등)과 함께, 검색어 입력 또는 **`상세 검색`을 펼쳐 `작성일`, `#태그`, `@사람` 조건으로 원하는 메모를 빠르게 걸러낸 화면**을 캡처합니다.

### [캡처 3] AI 활용 (`AI로 정리` — `자주 하는 업무` 및 `[M번호]` 출처·다듬기) — *슬라이드 4용*
- **촬영 포인트:** **AI로 정리** 탭에서 **`자주 하는 업무` 저장/불러오기 영역**이나, 생성된 결과물 본문 내 **`[M1]`, `[M2]` 원문 열기 링크** 및 하단 **`직접 수정` / `다듬기`** 버튼이 보이는 화면을 캡처합니다.

### [캡처 4] 다른 앱 메모 & 개별 문서 가져오기 (`다른 앱에서 가져오기`) — *슬라이드 5용*
- **촬영 포인트:** 스티커 메모 / 삼성 노트 / 에버노트(`.enex`) / Redmine 가져오기 화면이나, **`파일을 메모로 가져오기`**에서 한글(`.hwp`/`.hwpx`)·PDF·개별 엑셀의 구역/시트 텍스트 미리보기와 체크박스 선택 화면을 캡처합니다.

### [캡처 5] 부서별 엑셀 폴더 일괄 취합 & 분석 (`엑셀 폴더 취합`) — *슬라이드 6용 (신규 추가!)*
- **촬영 포인트:** **가져오기·공유 → 문서 가져오기 → 엑셀 폴더 취합**에서 여러 엑셀 파일이 한 표로 합쳐진 **취합 결과 표 / 묶음 집계 화면**(파일·행 수, 행별 출처 보기, `엑셀로 저장`, `이 자료를 AI로 정리` 버튼 또는 `[C번호]` 출처가 달린 AI 분석 결과)을 캡처합니다.

### [캡처 6] 쉽게 공유 (`가져오기·공유 → 동료와 주고받기`) — *슬라이드 7용*
- **촬영 포인트:** **동료와 주고받기**에서 `#태그`·기간으로 추린 보낼 메모(또는 받은 `.json` 파일)의 목록·본문을 미리 보고 체크박스로 선택해 비밀번호 암호화로 내보내거나 가져오는 화면을 캡처합니다.

### [캡처 7 & 8] 프로그램 설치 및 첫 실행 화면 — *부록 A(슬라이드 10)용*
- **[캡처 7] 촬영 포인트:** `memoinall-Setup-0.1.0.exe`를 실행했을 때 뜨는 Windows 설치 마법사 화면(설치 위치 확인 또는 바탕화면 바로가기 선택 화면)을 캡처합니다.
- **[캡처 8] 촬영 포인트:** 설치 완료 화면이나 시작 메뉴에서 처음 실행된 화면(사이드바에 검색 모델 준비/완료 상태가 표시된 화면 등)을 캡처합니다.

### [캡처 9] 사용할 AI 초기 세팅 화면 (`더 보기 → 설정`) — *부록 B(슬라이드 11)용*
- **촬영 포인트:** **더 보기 → 설정**에서 사용할 AI(Claude · ChatGPT · Gemini · Ollama 등)를 고르고, API 키(마스킹 표시)·모델 선택 및 **`연결 테스트` 성공 메시지**가 표시된 화면을 캡처합니다.

## 4. 💿 부록: 동료 배포용 설치 및 초기 세팅 안내문

동료들에게 설치 파일을 공유하거나 게시판에 함께 안내할 때 그대로 복사해 사용할 수 있는 가이드입니다.

> ### 🛠️ `memoinall` 1분 설치 및 AI 세팅 방법
> 
> **1단계: 프로그램 설치 (`memoinall-Setup-0.1.0.exe`)**
> 1. 첨부된 `memoinall-Setup-0.1.0.exe` 파일(약 46MB, Windows 10/11 64비트용)을 내려받아 실행합니다.
> 2. Python 설치나 관리자 권한이 필요하지 않으며, 기본 경로(`%LOCALAPPDATA%\Programs\memoinall`)에 바로 설치됩니다.
> 3. 바탕화면 바로가기 만들기를 체크하고 설치를 완료한 뒤, 시작 메뉴 또는 바탕화면에서 **`memoinall`**을 실행합니다.
>    - *참고:* 첫 실행 시 의미 검색에 필요한 모델을 백그라운드로 자동 준비하며, 준비 중에도 기다리지 않고 바로 메모 작성·저장·키워드 검색을 사용하실 수 있습니다.
>    - *데이터 보존:* 작성한 메모와 설정은 `%USERPROFILE%\.memoinall`에 별도 저장되므로 추후 새 버전을 덮어써 업데이트하거나 프로그램을 삭제해도 메모는 안전하게 유지됩니다.
> 
> **2단계: 사용할 AI 세팅 (`더 보기 → 설정`)**
> 1. 앱 상단 메뉴에서 **[더 보기 → 설정]**을 클릭합니다.
> 2. **Claude · ChatGPT · Gemini · Ollama** 중 본인이 사용할 AI 프로바이더를 선택합니다.
> 3. API 키를 입력하고 모델을 선택한 뒤(`서버에서 모델 목록 불러오기` 지원), 저장하기 전에 **`[연결 테스트]`** 버튼을 눌러 정상 연결을 확인하고 **`[저장]`**을 누릅니다.
>    - *Tip:* 별도의 API 키가 없더라도 설정 없이 **[AI로 정리]**를 실행하면 관련 메모 근거가 정리된 **완성형 프롬프트**를 만들어주므로, 사내 AI나 무료 웹 챗봇에 그대로 복사·붙여넣어 활용하실 수 있습니다!
