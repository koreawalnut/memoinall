# 문서 파일을 메모로 가져오기

## 사용 방법

1. **가져오기·공유 → 다른 앱에서 가져오기**를 연다.
2. **파일을 메모로 가져오기**에서 문서를 선택한다.
3. 추출된 텍스트를 읽고, 필요한 시트·페이지·구역을 체크한다. 텍스트를 직접 수정할 수도 있다.
4. **선택한 N개를 메모로 저장**을 누른다. 선택한 부분마다 메모가 만들어진다.
5. 저장한 메모를 열어 확인하거나 **이 자료를 AI로 정리**를 누른다.

미리보기만으로는 메모가 저장되지 않는다. 다른 메뉴에 다녀와도 미리보기의 선택과 수정은 유지된다.
미리보기에서 수정한 내용을 저장하지 않고 창을 닫거나 새 파일을 열면 변경 확인을 거친다.

## 지원 형식

| 형식 | 저장 단위와 처리 |
|---|---|
| Excel `.xlsx`, `.xlsm`, `.xls` | 시트마다 메모 하나. 시트 이름·행 번호·셀 순서를 표시한다. 숨겨진 시트는 제외한다. |
| PDF `.pdf` | 텍스트가 있는 페이지마다 메모 하나. 텍스트를 읽지 못한 페이지 번호를 안내한다. |
| 한글 `.hwp` | HWP 5.x의 본문 구역마다 메모 하나. 압축된 본문과 표 안의 문단 텍스트를 읽는다. |
| 한글 `.hwpx` | 문서의 읽기 순서에 따라 구역별 본문 텍스트를 읽는다. |
| `.txt`, `.md` | 파일의 텍스트 전체를 메모 하나로 읽는다. UTF-8·UTF-16·CP949를 지원한다. |

엑셀은 저장된 셀 값을 읽고 수식을 계산하지 않는다. XLSX/XLSM에서 저장된 계산 결과가 없으면 수식 자체를 표시하고 안내한다.
숫자 서식·차트·이미지는 가져오지 않으며, PDF와 한글의 복잡한 표·단·원본 배치는 텍스트에서 달라질 수 있다.
추출된 내용이 실제 원문과 맞는지 미리보기에서 확인해야 한다.

이미지로만 된 스캔 PDF나 그림·필기는 OCR을 수행하지 않는다. 해당 페이지를 알리거나, 읽을 수 있는 텍스트가 전혀 없으면 저장 대신 OCR 안내를 표시한다.
이 구분은 [pypdf의 텍스트 추출 문서](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)에 설명되어 있다.

## 저장과 중복 처리

- 파일명과 원본 위치를 메모 본문에 남긴다. 자동으로 `#문서`와 형식 태그를 붙여 검색과 AI 근거에 사용할 수 있다.
- 메모 작성 시각은 **메모로 저장한 시각**이다. 원본 문서의 작성 시각을 추측하지 않는다.
- 같은 파일명·원본 위치·본문을 다시 저장하면 이미 저장한 메모를 반환한다. 수정한 본문은 새 메모로 저장한다.
- 파일의 바이너리는 앱 내부 서버에서 읽은 뒤 버린다. 디스크에는 사용자가 저장한 텍스트 메모만 남는다.
- 문서 추출 과정에서 외부 AI를 호출하지 않는다. 저장 후 AI 정리는 기존 AI 설정에 따라 동작한다.
- 선택한 여러 부분은 하나의 DB 트랜잭션으로 저장한다. 중간에 오류가 나면 해당 요청의 메모와 검색 색인을 함께 되돌린다.

## 제한

- 파일당 20MB, 추출 텍스트 합계 100만 자, 최대 500개 페이지·시트·구역.
- 엑셀은 최대 20만 셀. 압축 문서는 압축 해제 크기 제한도 적용한다.
- 암호·보안 문서와 배포용 HWP는 지원하지 않는다. 읽을 수 있는 사본으로 가져와야 한다.
- HWP 3.x는 지원하지 않는다. 한글에서 HWPX 또는 텍스트 PDF로 다시 저장해 가져온다.
- 원본 문서를 첨부파일로 보관하는 기능과 OCR은 포함하지 않았다.

## 설치와 실행

프로젝트의 기본 `requirements.txt`에 문서 파서가 포함되어 있다. 기존 개발 환경에는 문서 의존성만 추가할 수 있다.

```powershell
python -X utf8 -m pip install -r requirements-documents.txt
```

이번 작업에서 프로젝트 폴더 안에 `.venv`를 만들고 문서 의존성을 설치했다. 이 환경으로 실행하려면 다음을 사용한다.

```powershell
.\.venv\Scripts\python.exe desktop_main.py
# 또는 웹 서버
.\.venv\Scripts\python.exe run.py
```

`build_exe.py`는 현재 Python에 패키지가 부족하면, 필수 패키지가 준비된 프로젝트 `.venv`로 자동 전환한다.
PyInstaller 스펙은 문서 파서들을 명시적으로 포함한다. 기존 배포 `.exe`는 재빌드해야 새 기능이 반영된다.
환경 자동 선택 수정 후 실제 빌드를 완료했고, `dist/memoinall.exe`에 문서 파서가 포함된 것을 확인했다.

```powershell
python build_exe.py --check
python build_exe.py
```

## 검증과 참고

- 실제 파일 구조로 생성한 XLSX·XLS·PDF·HWP·HWPX 자료로 추출과 오류 처리를 검증했다. HWP는 CFB 컨테이너·압축 본문·문단 제어·UTF-16 문자를 포함한다.
- 문서 추출·API·저장·중복·롤백 검증 45개와, 브라우저의 업로드·편집 유지·부분 저장·검색·AI 연결 흐름을 검증했다.
- 실제 사용자 문서나 모든 한글 버전·복잡한 표의 추출 품질을 검증한 것은 아니다.
- 테스트 추가 의존성은 `requirements-test.txt`에 있다. `xlwt`는 구형 XLS 테스트 자료 생성에만 쓰이며 앱 배포에는 필요 없다.

```powershell
.\.venv\Scripts\python.exe -X utf8 tests/test_documents.py
.\.venv\Scripts\python.exe -X utf8 tests/test_ui.py
```
