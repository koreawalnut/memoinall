# 에버노트 가져오기와 공유 대상 확인

## 출처 태그와 시간 표시

외부 앱에서 가져오면 `#에버노트`, `#스티커메모`, `#삼성노트`, `#Redmine`, `#텍스트파일` 중
해당 출처 태그가 자동으로 붙습니다. 원래 태그는 유지하고 같은 태그를 중복해서 붙이지 않습니다.
문서 파일은 기존처럼 `#문서`와 파일 형식 태그가 붙습니다. 동료가 보낸 메모 파일은 원래 태그를 유지합니다.
가져오기 직후부터 태그로 찾을 수 있습니다.

기존에 가져온 메모에도 앱 실행 후 백그라운드에서 한 번 출처 태그를 보완합니다.
이 작업으로 작성·수정 시각은 바뀌지 않으며, 이후 직접 지운 태그를 실행할 때마다 되붙이지 않습니다.
자동 태그를 붙이기 전에 공유했던 파일도 같은 내용이면 다시 저장하지 않습니다.

시간은 이 PC의 현지 시각을 `2026-11-09 14:30`처럼 24시간제로 표시합니다.
메모 상세 화면에서 작성 시각과 수정 시각을 구분합니다.
구버전에서 Redmine·스티커 메모의 시간대를 누락한 경우, 해당 앱에서 **가져오기**를 다시 실행하면
원본과 대조해 잘못된 시각만 바로잡습니다. **이미 가져온 메모도 갱신**을 켤 필요는 없습니다.
직접 수정한 본문과 수정 시각은 유지합니다. 원본을 확인할 수 없는 시각은 임의로 바꾸지 않습니다.

## 에버노트에서 옮기기

1. Evernote Windows/Mac 앱에서 메모 또는 노트북을 선택하고 **내보내기 → ENEX**를 선택합니다. 태그·작성일·수정일도 내보내세요.
2. memoinall의 **가져오기·공유 → 다른 앱에서 가져오기 → 에버노트에서 가져오기**에서 `.enex` 파일을 선택합니다.
3. 목록에서 제목·본문을 검색하고 **본문 확인**을 펼쳐 내용을 확인합니다. 필요 없는 메모는 체크를 해제합니다.
4. **선택 N건 가져오기**를 누릅니다. 미리보기만으로는 저장하지 않습니다.

제목, 텍스트, 링크, 체크리스트, 작성·수정 시각, 태그를 가져옵니다. 날짜는 이 PC의 현지 시각으로 변환합니다.
태그의 공백은 밑줄로 바꾸고, 앱의 태그 규칙에 맞지 않는 이름은 본문에 원문으로 보존합니다.
노트북별로 구분하려면 파일을 나눠 내보내고 가져오기 옵션에서 분류용 태그를 붙이세요.

이미지·첨부파일의 실제 데이터, 서식, 암호화된 본문은 옮기지 않습니다. 첨부 위치·이름과 암호화된 부분의 표시를
텍스트로 남기고 목록에 주의사항을 보여 줍니다. 원본 ENEX는 보관하세요. 암호화된 내용이 필요하면 Evernote에서
암호를 해제한 뒤 다시 내보내야 합니다. 이 기능은 ENEX 파일을 읽는 방식이며 계정 동기화 기능은 아닙니다.

같은 내용을 다시 가져오면 건너뜁니다. ENEX에는 안정적인 메모 ID가 보장되지 않아 **내용을 수정한 뒤 다시 내보낸
메모는 새 메모로 취급**합니다. 기존 메모를 자동으로 찾아 덮어쓰지는 않습니다.
UI 파일당 제한은 **50MB·1,000건**이며 넘으면 나눠 내보내야 합니다.

Evernote의 내보내기 절차는 [공식 도움말](https://help.evernote.com/hc/en-us/articles/209005557-Export-Notes-and-Notebooks-as-ENEX-or-HTML),
본문 구조는 [ENML 명세](https://dev.evernote.com/legacy/doc/articles/enml)를 참고했습니다.

CLI에서도 지원합니다. `--commit`을 생략하면 읽기만 합니다.

```powershell
python -m memoinall import --source evernote --evernote-file "C:\notes\archive.enex"
python -m memoinall import --source evernote --evernote-file "C:\notes\archive.enex" --commit
```

## 동료와 주고받기

**보낼 때:** 내 메모에서 고르거나 공유 화면에서 태그·기간으로 범위를 좁히고 **무엇이 나가는지 보기**를 누릅니다.
목록 전체를 50건씩 표시하며 제목·본문 검색, 검색 결과 일괄 선택/해제, 선택한 메모만 보기를 지원합니다.
검색하거나 페이지를 바꿔도 체크는 유지됩니다. 선택 건수는 목록 전체 기준입니다.
의미 검색의 결과에는 관련성이 낮은 메모도 포함될 수 있으니 본문을 확인하고 제외하세요.

체크한 ID만 파일 저장·내용 복사에 전달합니다. 미리보기 이후 새 메모가 생겨도 추가되지 않습니다.
선택한 메모의 내용이 수정되거나 삭제되면 다시 확인하라는 메시지를 보여 줍니다.
범위 조건을 바꿨을 때도 목록을 다시 확인해야 합니다. 비밀번호와 파일 암호화는 기존과 동일합니다.
한 번에 1,000건까지 검토할 수 있으며 그 이상이면 태그·기간으로 범위를 좁혀주세요.

**받을 때:** `.json` 파일을 열고 필요한 메모만 체크합니다. 암호화된 파일은 비밀번호를 먼저 입력합니다.
이미 있는 메모·같은 내용·너무 짧은 내용은 건너뛰는 이유를 표시합니다. 선택이 0건이면 저장하지 않습니다.
파일 또는 가져오기 옵션이 바뀌면 다시 미리보기부터 확인합니다. ENEX와 받은 파일은 일괄 가져오기 대상에서
제외되며 각각의 목록에서 선택합니다.
