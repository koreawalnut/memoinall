01. 기획 배경 및 새로운 정의

흩어진 메모와 문서, 왜 정작 필요할 땐 찾지 못하고 다시 쓸까?

기록할 때의 ‘분류 부담’을 없애고, 검색·AI 문서화·가져오기·공유를 하나의 흐름으로 연결

창의적 업무 재정의
😫 기존 업무 메모·문서 관리의 3대 불편 (AS-IS)
  • 적는 순간 분류를 강요하는 피로감: 회의나 전화 중 폴더, 제목, 양식을 먼저 맞추려다 보니 기록을 미루거나 스티커 메모·메모장에 대충 적어두고 잊어버림
  • 여러 앱과 파일에 파편화된 기록: 스티커 메모, 삼성 노트, 에버노트, Redmine, 그리고 엑셀·한글(.hwp)·PDF 문서에 내용이 흩어져 있어 통합 검색이 불가능
  • AI 활용과 메모 공유의 번거로움: 내 메모를 AI로 정리하려면 관련 기록을 일일이 찾아 복사·붙여넣어야 하고, 동료에게 필요한 메모만 골라 전달하기도 까다로움
🚀 memoinall의 해결 방식 (TO-BE)
  • 적을 땐 무형식, 꺼낼 땐 구조화: 입력창 하나에 양식 없이 바로 적으면(초안 자동 보관), 백그라운드에서 색인·태그·사람 정보를 자동으로 정리
  • 의미 + 한글 키워드 하이브리드 검색: 정확한 단어가 기억나지 않아도 문맥으로 빠르게 찾고, 태그·사람·작성일 조건으로 정확히 좁힘
  • 출처 기반 AI 정리 & 외부 가져오기·공유: 세팅한 AI로 내 메모를 근거 삼아 [M번호] 원문 링크가 달린 정리본을 만들고, 외부 메모·문서 반입과 동료 공유를 한곳에서 처리

02. 주요 기능 ① — 쉽게 메모하고, 빠르게 검색하기 (내 메모 & #태그 활용)

형식 없이 적고 #태그만 붙여두면, 언제든 주제별로 즉시 찾아낸다

작성 내용 유실을 막는 초안 보호와 한글 하이브리드 검색 · #태그 필터의 결합

핵심 주안점 1 & 2
✍️ 1. 쉽게 메모 & 간편한 #태그 지정
  • 단일 입력창 & Ctrl+Enter 즉시 저장: 제목이나 폴더를 먼저 고를 필요 없이 떠오르는 업무 내용을 그대로 입력 (초안 자동 보관·복원)
  • 작성 중에도, 저장 후에도 쉬운 #태그 관리: 본문에 #업무명을 바로 적거나 ‘태그 추가’에서 선택할 수 있고, 이미 저장한 메모도 상세 화면에서 새 태그 입력·기존 태그 선택·제거(×) 시 본문과 검색 색인이 즉시 동기화됨
⚡ 2. 빠르게 검색 — 하이브리드 검색 & #태그 필터
  • #태그로 주제·업무별 모아보기: 업무나 프로젝트별 태그(예: #예산, #인수인계, #회의)만 클릭하면 관련 메모만 즉시 필터링되며, 선택한 태그 범위를 그대로 AI 정리나 동료 공유로 연결 가능
  • 의미 검색 + 한글 2-gram 검색 결합(RRF): 조사(‘회의록을’)가 붙어 있거나 정확한 단어가 기억나지 않는 애매한 표현도 #태그·작성일·@사람 조건과 조합해 정확히 탐색
📸 2
[캡처 2] ‘내 메모’ 작성 및 검색·상세 필터 화면
메모 입력창(‘초안 보관됨’ 표시)과 함께, 검색창 및 상세 검색(작성일·태그·사람 조건)으로
원하는 업무 메모를 빠르게 찾아낸 목록 화면을 캡처해 넣어주세요.

03. 주요 기능 ② — 원하는 AI를 세팅하고 내 메모를 근거로 결과물 만들기 (AI로 정리)

내가 고른 메모와 검색 근거로 ‘출처([M번호]) 붙은 문서’ 즉시 생성

사용할 AI 프로바이더를 유연하게 세팅하고, 환각 없이 근거가 검증된 보고서·인수인계서 작성

핵심 주안점 3 (AI 활용)
⚙️ 1. 사용할 AI 간편 세팅 (더 보기 → 설정)
  • 원하는 AI 선택 및 연결 테스트: 설정 화면에서 Claude · ChatGPT · Gemini · Ollama(또는 OpenAI 호환 서버) 중 사용할 AI와 모델·API 키를 세팅
  • 저장 전 연결 테스트 지원: 키나 모델명을 잘못 입력하지 않도록 저장 전에 즉시 연결 상태를 확인하고, 서버에서 사용 가능한 모델 목록도 바로 불러옴
  • 프롬프트 생성 모드: API 키를 세팅하지 않은 환경에서도 검색된 근거가 정리된 완성형 프롬프트를 뽑아 사내 웹 AI 등에 붙여넣어 활용 가능
📑 2. 근거 직접 지정 & 원문 링크([M번호]) 문서 생성
인수인계서 보고서 브리핑 개요/목차 목록 정리 이메일 초안 질문에 답하기
  • 다각도 자동 검색 또는 직접 선택: 지시사항에서 다각도 검색어를 도출해 근거를 찾거나, 체크박스로 내가 직접 고른 메모만 근거로 지정해 AI 문서 생성
  • 원문 즉시 대조: 결과물의 [M번호]를 클릭하면 해당 원본 메모가 바로 열려 사실 여부를 즉시 확인 (기록에 없는 내용은 지어내지 않도록 제어)

04. 주요 기능 ③ — 다른 앱의 메모와 업무 문서를 쉽게 가져오기

스티커 메모·삼성 노트·에버노트부터 엑셀·한글(HWP)·PDF까지 한곳으로!

미리보기로 내용을 확인·편집하고 필요한 항목만 깔끔하게 골라 담는 가져오기 워크플로우

핵심 주안점 4 (쉽게 가져오기)
🗂️ 1. 기존 메모 앱 & 협업 툴 기록 간편 가져오기
  • Windows 스티커 메모 & 삼성 노트: PC에 저장된 기존 메모 DB를 원본 훼손 없이 읽어와 원래 작성 시각 그대로 통합 (불필요한 문단 ID 등 노이즈 자동 정리)
  • 에버노트(.enex) 선택 가져오기: 내보낸 파일에서 제목·본문을 검색하고 본문 확인 및 체크박스 선택으로 필요한 노트만 쏙 골라 반입
  • Redmine 연동: 주소와 API 키를 세팅해 이슈·위키·문서·공지를 종류별·기간별로 가져오기 지원
📄 2. 엑셀·한글(HWP/HWPX)·PDF 문서 파일을 메모로 가져오기
  • 다양한 행정 문서 직접 읽기: 엑셀(.xlsx/.xlsm/.xls 시트별), 한글(.hwp/.hwpx 구역별), PDF(페이지별), 텍스트(.txt/.md) 지원
  • 미리보기·편집 후 선택 저장: 추출된 텍스트를 눈으로 확인하고 직접 다듬은 뒤, 원하는 시트·페이지·구역만 체크해 메모로 저장하고 곧바로 ‘이 자료를 AI로 정리’로 연결!

05. 주요 기능 ④ — #태그와 선택 체크로 동료와 쉽게 주고받기

#태그 하나로 공유할 업무 범위를 추리고, 눈으로 확인 후 안전하게 전달

일일이 메모를 찾지 않아도 태그·기간 조건과 체크박스로 간편하게 주고받는 양방향 공유

핵심 주안점 5 (쉽게 공유)
🤝 1. 보낼 때 — #태그로 한 번에 추리고 확인 후 핀셋 공유
  • #태그·기간 조건 또는 직접 선택: 메모를 하나씩 찾을 필요 없이 특정 #태그(예: #인수인계, #프로젝트A)나 작성일·사람 조건으로 보낼 범위를 한 번에 좁히거나 체크박스로 직접 선택
  • ‘무엇이 나가는지 보기’ 사전 검토: 내보내기 전 대상 목록 전체를 검색·본문 확인하며 불필요한 개인 메모를 체크 해제 가능
  • AES-256-GCM 비밀번호 암호화: 비밀번호를 지정하면 공유 파일(.json)이 암호화되어 사내 메신저·이메일로도 안전하게 전달
📥 2. 받을 때 — 찾아보기로 열어 필요한 메모만 선택 반입
  • 파일 찾아보기 & 자동 미리보기: 동료에게 받은 .json 파일을 선택(암호화 파일은 비밀번호 입력)하면 들어있는 메모 목록·태그·본문을 즉시 미리보기
  • 선택 저장 및 자동 중복 제외: 이미 내 DB에 있는 동일한 메모는 자동으로 안내·건너뛰고, 내가 체크한 메모만 태그와 함께 그대로 저장
📸 5

Python 설치도, 관리자 권한도 필요 없는 1분 원클릭 설치

부록 1: 설치 가이드
💿 1단계: 설치 파일 실행 (Windows 10/11 x64)
  • memoinall-Setup-0.1.0.exe(약 46MB) 더블클릭: 별도의 개발 환경(Python 등)이나 관리자 권한 없이 현재 사용자 폴더(%LOCALAPPDATA%\Programs\memoinall)에 즉시 설치됩니다.
  • 바로가기 자동 등록: 시작 메뉴에 memoinall이 등록되며, 바탕화면 바로가기 생성 여부를 선택할 수 있습니다. (무설치 단일/폴더 실행 파일 방식도 지원)
🚀 2단계: 앱 첫 실행 및 백그라운드 검색 모델 준비
  • 기다림 없는 즉시 사용: 첫 실행 시 의미 검색용 임베딩 모델을 백그라운드로 자동 다운로드하며, 내려받는 동안에도 즉시 메모 작성·저장·키워드 검색을 사용할 수 있습니다.
  • 안전한 데이터 분리 보관: 메모 DB와 설정·모델은 %USERPROFILE%\.memoinall에 별도 보관되어, 새 버전을 덮어써 업데이트하거나 앱을 제거해도 작성한 메모는 삭제되지 않습니다.
