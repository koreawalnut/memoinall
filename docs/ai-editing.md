# AI로 정리한 내용 이어서 쓰기

AI 정리 화면의 기본 동작은 **정리하기**, **직접 수정**, **메모로 저장**, **다듬기**입니다.
예전 결과와 참고 자료는 필요할 때 펼쳐볼 수 있습니다.

## 자주 하는 업무 저장·공유

AI 정리 화면의 **자주 하는 업무**는 기본적으로 접혀 있습니다. 평소처럼 요청을 입력해 정리할 수 있습니다.
반복할 업무가 있으면 요청·태그·형식을 정한 뒤 **자주 하는 업무 → 현재 설정 저장**을 누르세요.
업무 이름과 기간을 확인하고 저장합니다. 기간은 기존 **찾을 범위 바꾸기** 안에서도 고를 수 있습니다.

다음에는 목록에서 업무를 골라 **불러오기 → 정리하기**를 누릅니다. 불러오기만으로 AI를 호출하지 않습니다.
**이번 주**는 월요일부터 오늘, **지난주**는 지난 월요일부터 일요일, **이번 달**은 1일부터 오늘,
**최근 30일**은 오늘을 포함한 30일입니다. 실행하는 PC의 날짜 기준으로 매번 계산합니다.
체크한 메모 ID는 저장하지 않으며, 저장한 태그·기간에 맞는 메모를 다시 찾습니다.

**관리·공유 → 파일로 공유**로 현재 창의 업무 설정을 `.json` 파일에 담을 수 있습니다.
메모 본문·정리 결과·AI 연결 설정은 포함하지 않습니다. 업무 이름·요청문·태그·기간·형식과 추가 조건은 포함됩니다.
받는 사람은 **관리·공유 → 받은 업무 가져오기**에서 내용을 확인하고, 필요한 태그를 자기 팀에 맞게 바꿔 저장합니다.
같은 이름이 있어도 덮어쓰지 않고 새 이름을 제안합니다. 없는 태그는 안내하며, 제한을 자동으로 해제하지 않습니다.

관리 창에서 수정·삭제할 수 있고 삭제 대상은 업무 설정뿐입니다. 저장하지 않은 변경은 닫기 전에 확인합니다.
다른 업무를 불러올 때는 수정 중인 AI 결과를 먼저 보관하며, 보관에 실패하면 기존 내용을 유지합니다.

## 참고할 메모 고르기

**태그로 범위 좁히기**를 펼치고 원하는 태그를 누르면 해당 태그가 붙은 메모에서만 찾습니다.
`#에버노트`, `#스티커메모` 같은 출처 태그와 직접 만든 태그를 모두 선택할 수 있습니다.
태그가 많으면 이름으로 검색하세요. 여러 개를 고르면 **그 태그가 모두 붙은 메모만** 대상입니다.
**태그 해제**를 누르면 태그 제한을 없앱니다.

태그를 바꾸면 이전 메모 선택은 비워집니다. **메모 고르기**에서 새 범위의 대상을 확인하세요.
정리할 내용을 입력하기 전의 메모 목록, **메모 더 찾기**, 실제 정리 요청에 모두 같은 범위를 적용합니다.
조건에 맞는 메모가 없으면 다른 메모로 범위를 넓히지 않고 안내합니다.
이전 결과를 다시 열 때도 그때 사용한 태그 범위를 보여 줍니다.

내 메모에서 여러 건을 선택한 뒤 **AI로 정리**를 누르거나, AI 정리 화면의 **메모 고르기**를 누릅니다.
체크를 해제한 메모는 AI 요청에 포함되지 않습니다. **본문 확인**으로 내용을 펼쳐볼 수 있고,
**메모 더 찾기**에서 빠진 자료를 찾아 추가할 수 있습니다.

정리할 내용을 적기 전에도 메모부터 고를 수 있습니다. 모든 체크를 해제하면 정리 버튼이 꺼집니다.
고른 원문이 수정되거나 삭제되면 다시 확인하라는 메시지를 보여 줍니다.
자료가 너무 길면 일부만 사용하거나 제외할 수 있으며 해당 내용을 화면에 표시합니다.
**찾을 범위 바꾸기 → 읽을 분량**에서 늘릴 수 있습니다.

## 직접 고치고 보관하기

만든 결과는 자동으로 **이전 결과**에 보관됩니다. **직접 수정**을 누르면 본문을 편집할 수 있습니다.
입력 중인 내용도 잠시 후 PC의 데이터베이스에 보관됩니다. 앱을 다시 열어 **AI로 정리**로 들어오면
가장 최근 결과와 보관된 수정 내용이 복원됩니다. 보관 실패 시 메시지를 표시하고 다른 결과로 교체하지 않습니다.

**수정 완료**를 누르면 고친 내용을 기록하고 읽기 화면으로 돌아옵니다.
**메모로 저장**을 누르면 현재 내용을 내 메모에 추가합니다. 저장한 메모에는 **AI로 정리** 표시와
참고한 메모 목록이 붙습니다. 같은 결과를 다시 저장해도 중복 메모가 생기지 않습니다.
내 메모에서 별도로 수정한 내용은 AI 결과를 다시 저장한다고 덮어쓰지 않습니다.
AI 화면에서 내용이 바뀐 뒤 저장하면 새 메모가 추가됩니다.

보관된 AI 결과는 **메모로 저장**하기 전까지 일반 메모 검색에 포함되지 않습니다.
복사와 파일 저장은 직접 수정한 내용까지 반영합니다.

## AI에게 다듬기 요청하기

결과 아래 **어떻게 바꿀까요?**에 “결정 사항만 남겨줘”처럼 적고 **다듬기**를 누릅니다.
**더 짧게 / 보고용으로 / 표로 정리**는 요청을 채워주는 빠른 버튼이며, 다듬기를 눌러야 AI를 호출합니다.

직접 고친 문장과 당시 참고한 메모를 함께 사용합니다. 관련 없는 메모를 새로 검색해 넣지 않습니다.
원문을 나중에 수정하거나 지워도 당시 사용한 참고 내용은 결과와 함께 남습니다.
다듬기에 실패하면 기존 내용과 직접 고친 내용을 유지하고 다시 시도할 수 있습니다.
실제 문장 품질과 처리 시간은 연결한 AI에 따라 달라집니다.

**이전 내용 보기**에서 처음 만든 내용, 직접 고친 내용, AI로 다듬은 내용을 확인하고 되돌릴 수 있습니다.
되돌리기 전 내용과 보관 중인 수정 내용도 기록에 남습니다.

## 저장과 검증

결과·수정 중인 내용·참고 메모는 기존 `memo.db`의 `ai_results`, `ai_versions`에 저장합니다.
설치 폴더와 별도인 기존 사용자 데이터 위치를 사용하며 기존 메모 스키마는 유지합니다.
기본 사용자 데이터 위치는 `%USERPROFILE%\.memoinall`입니다.

검증은 `tests/test_ai_history.py`, `tests/test_ai_ui.py`와 기존 생성·API·UI·시작 테스트로 수행합니다.
태그 범위는 `tests/test_ai_scope.py`, `tests/test_ai_scope_ui.py`에서 목록·검색·AI 요청·이전 결과까지 확인합니다.
반복 업무는 `tests/test_workflows.py`, `tests/test_workflows_ui.py`에서 저장·공유·기간 계산·수정 보호·화면을 확인합니다.
AI 호출은 테스트용 응답으로 대체하고, 실제 SQLite 저장과 Chromium의 사용자 동작은 그대로 실행합니다.
